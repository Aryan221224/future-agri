Future Agri Mission Console - Windows
=====================================

1. Unzip this folder anywhere (for example Documents\FutureAgri).
2. Double-click FutureAgri.exe. A console window opens and the Mission Console opens in your
   browser at http://127.0.0.1:8099. Close the console window to stop it.

* No Python or installation is needed.
* Your farms and plans are kept in %USERPROFILE%\.futureagri, so they survive updates:
  unzip a newer version and start it the same way.
* The console is reachable only from this computer.
* Options: FutureAgri.exe --port 8100 (another port), FutureAgri.exe --no-browser.
* Windows SmartScreen may warn that the app is unrecognised (it is not code-signed):
  choose "More info" then "Run anyway".
