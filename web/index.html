Calibration monitor

Observed conformal coverage against nominal, per stratum. An alarm means the calibration set is no longer exchangeable with what the model is seeing — a new season, cultivar or light regime. The fix is to recalibrate, not to widen the interval.

Review queue

Findings whose conformal prediction set was not a singleton. An empty set means out-of-distribution; more than one means genuine ambiguity. Both go to a human rather than into an automated decision.
